Starting with GIT Basic Commands

create git folder to track all the commands while learning into that folder

mkdir git-learning
ls and see the created folder 

cd git-learning to actually go into the folder and create file
check this folder with ls - since no file was created ,it will show empty

git init to initaite to create a git file
check with ls -al as the .git extension file is created and is in hide

now to put something into the file 
echo "Starting with GITBasic Commands" >GettingStartedWithGIT.txt   -> naming the file along eith writing the content

cat GettingStartedWithGIT.txt to check the content is updated 


git init - to initiate an empty directory
git status to chekc the status o f the file.

at this point if i check the git status it will give me the file under untracked files as we didnt commit
